# SIK Hemsida

Anpassad version av `softwarechasers7/Al-Furqan-islamic-Center`.

## Klart

- Mallen är uppackad till vanliga projektfiler.
- Startsida, om-sida, bönetider, verksamhet och kontakt är omskrivna för SIK - Somaliska Islamiska Kulturföreningen.
- Stöd-sida för medlemskap, månadsgåva och donation är tillagd.
- Trasig placeholder-text och gamla kontaktuppgifter är borttagna från huvudsidorna.
- `css/custom.css` lägger SIK-färger och layoutförbättringar ovanpå originalmallen.

## Att fylla i innan publicering

- Riktig adress.
- Rätt organisationsnummer och föreningsnamn.
- Telefon och e-post.
- Officiella bönetider.
- Swishnummer, bankgiro och eventuell kortbetalningslänk.
- Medlemsavgift och villkor för månadsbetalning.
- Egna bilder från lokalen eller verksamheten.
- Eventuell Google Maps-inbäddning.
